== About The Project

This repository used to publish the LinxPhotos organization homepage. That page now redirects to https://linx.photos/. Privacy and terms redirect to the same documents on linx.photos. Product copy from the old page (client galleries, InstaLay mattes and tapestries, docs, and the GitHub org) lives on that site.

== Usage

* Portfolio and org home → https://linx.photos/
* Privacy → https://linx.photos/privacy-policy
* Terms → https://linx.photos/terms-of-service
* InstaLay → https://instalay.linx.photos/ (download: https://instalay.linx.photos/download)
* Docs → https://docs.linx.photos/ (https://github.com/LinxPhotos/docs)

The old project path https://linxphotos.github.io/InstaLay/ is not the InstaLay site. InstaLay is served on its own domain.
